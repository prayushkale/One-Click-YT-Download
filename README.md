# One-Click-YT-Download

## Setup instructions

1. Install Python: https://www.python.org/downloads/release/python-3109/

2. Download and Setup yt-dlp: https://github.com/yt-dlp/yt-dlp?tab=readme-ov-file#installation

3. Install Google API Python Client: https://pypi.org/project/google-api-python-client/

4. Download and Setup Whisper: https://github.com/openai/whisper

5. Install ffmpeg: https://ffmpeg.org/download.html

## Run Script

1. python start.py

2. Type Channel name

3. Select what to download
